# 🛠️ Ace Hardware & Tools

A high-performance, premium e-commerce experience for professional hardware, construction materials, and power tools. Designed for reliability, speed, and a seamless user journey.

## 🚀 Modern Tech Stack

Our platform leverages a cutting-edge technological foundation to deliver a state-of-the-art experience:

### Frontend Excellence
*   **[React 18](https://reactjs.org/)**: For a declarative, component-based user interface.
*   **[TypeScript](https://www.typescriptlang.org/)**: Ensuring type safety and robust developer experience.
*   **[Vite](https://vitejs.dev/)**: Next-generation frontend tooling for blazing-fast development and builds.
*   **[Tailwind CSS](https://tailwindcss.com/)**: A utility-first CSS framework for bespoke, responsive designs.

### Backend & Infrastructure
*   **[Supabase](https://supabase.com/)**: An open-source Firebase alternative providing a powerful PostgreSQL database, authentication, and real-time capabilities.
*   **[PostgreSQL](https://www.postgresql.org/)**: The world's most advanced open-source relational database.

### Core Architecture
*   **[React Router 7](https://reactrouter.com/)**: Advanced client-side routing for seamless navigation.
*   **[React Context API](https://reactjs.org/docs/context.html)**: Clean, centralized state management without the overhead of external libraries.
*   **[Lucide React](https://lucide.dev/)**: A library of beautiful, consistent icons for a polished UI.

### Quality & Tooling
*   **[ESLint](https://eslint.org/)**: Pluggable linting utility for JavaScript and TypeScript.
*   **[PostCSS](https://postcss.org/)**: A tool for transforming CSS with JavaScript plugins.
*   **[Autoprefixer](https://github.com/postcss/autoprefixer)**: Automatically adding vendor prefixes to CSS.

## 🏗️ Project Structure

```text
src/
├── components/ # Reusable UI components
├── contexts/   # Global state management
├── lib/        # Third-party configurations (Supabase, etc.)
├── pages/      # Route-level components
├── types/      # TypeScript interfaces and types
└── App.tsx     # Main application routing and layout
```
